# Agent changes made from the daily review

Each entry: date, the evidence (counts and days), the old wording, the new wording. Revert an entry if the next 5 trading days score worse for the same category.

Never changed automatically: risk limits (`MAX_POSITIONS`, `MAX_SELL_IDEAS`, `CAPITAL_PER_TRADE`, stop and target percentages), the no-orders rule, the event-risk vetoes, an agent's tool list, anything under `btst/`, `.env*`. Those are proposed to the user instead.
